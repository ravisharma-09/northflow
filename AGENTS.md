# Repository Safety Rules

- Public website redesigns must not modify admin, CRM, authentication, API or Supabase behavior unless explicitly requested.
- Preserve existing forms, booking flows, analytics and integrations.
- Never publish fake client results, testimonials, logos or statistics.
- Fictional businesses must always be labelled Concept Demo.
- Use the repository's existing package manager and conventions.
- Run lint, type-check, tests and production build after material changes.
- Verify public UI at desktop and mobile widths.
- Ask before adding a production dependency.
